# ✈ ClawdGram

Мессенджер для своих: аккаунты, ники, профили с тегами, поиск людей, личные сообщения и общий чат.
Это обычная программа с окном (не сайт). Состоит из двух частей:

- `server.py` — запускается **у одного человека** (хранит аккаунты и сообщения)
- `client.py` — окно приложения, запускают **все друзья**

## Нужно
Python 3.9+ с сайта python.org (на Windows при установке поставь галочку «Add Python to PATH»).
Больше ничего ставить не надо.

## Запуск
1. Один человек запускает сервер: двойной клик по `start_server.bat` (или `python server.py`).
2. Каждый запускает клиент: `start_client.bat` (или `python client.py`).
3. В окне входа укажи адрес сервера, придумай ник и нажми «Регистрация».

## 📱 На телефоне (без установки)
1. Запусти сервер на ноутбуке. В окне сервера будет строка вроде `http://192.168.1.5:8765`.
2. Телефон должен быть в той же Wi‑Fi сети (или в общем VPN). Открой эту ссылку в Chrome.
3. Зарегистрируйся и пользуйся. Меню Chrome → «Добавить на главный экран» создаст ярлык.
Страница сама подстраивается под экран телефона, входит автоматически и переподключается, если пропал интернет.
Если страница не открывается, разреши серверу доступ в брандмауэре Windows (частная сеть).

## Как друзьям подключиться к твоему серверу
Если сервер на твоём ноутбуке:
- **Одна Wi‑Fi сеть:** адрес `ТВОЙ_IP:8765` (узнать IP: `ipconfig` в командной строке, строка IPv4).
- **Через интернет (проще всего):** все ставят бесплатный **Radmin VPN**, **ZeroTier** или **Tailscale**,
  заходят в одну сеть, и адрес сервера — это VPN‑адрес твоего ноута (например `26.12.34.56:8765`).
  Это ещё и шифрует трафик.
- Либо запусти сервер на любом всегда включённом компьютере/VPS.

Если Windows спросит про брандмауэр при запуске сервера, разреши доступ.

## Что умеет
- Регистрация и вход, пароли хранятся в виде хэша (PBKDF2)
- Уникальный ник + отображаемое имя, статус, «о себе», **теги**, цвет аватарки
- **Поиск людей** по нику, имени или `#тегу`
- Личные сообщения и **общий чат** для всех
- Онлайн/офлайн, «был(а) в…», «печатает…», счётчики непрочитанных (и в заголовке окна)
- История сообщений, удаление своих сообщений (правая кнопка мыши), копирование
- Эмодзи, Shift+Enter — новая строка

## Упаковать в .exe (чтобы друзьям не ставить Python)
На Windows запусти `build_exe.bat` — в папке `dist` появятся `ClawdGram.exe` (клиент) и `ClawdGramServer.exe`.

## Важно
- Трафик не шифруется (обычный TCP), поэтому для игры через интернет используй VPN из списка выше.
- База лежит в `clawdgram.db` рядом с сервером — делай копию, если сообщения важны.
- Не используй здесь пароли, которые у тебя на важных сайтах.
